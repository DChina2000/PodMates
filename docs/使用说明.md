# 群聊机器人面板 · 使用说明

一个程序管所有：QQ、微信小号、Discord、Telegram、LINE、YouTube、X 等平台，任意多个机器人角色，带长期记忆。
电脑上是一个窗口，手机用浏览器打开同一个面板。English version: [User-Guide.en.md](User-Guide.en.md).

---

## 一、安装

1. 双击 `PodMates-Setup-1.4.3.exe`。
2. 如果弹出蓝色的 **「Windows 已保护你的电脑」**：点 **「更多信息」** → 再点 **「仍要运行」**。
   （程序没买代码签名证书，所以 Windows 不认识它，这是正常的。）
3. 一路「下一步」。安装程序会问**安装位置**（默认装给自己用，不需要管理员权限；也可以选「为所有用户安装」，那要管理员权限）。默认会在桌面放一个图标「群聊机器人面板」。
4. 装完会自动打开。

> 数据（设置、角色、人设、人物表、记忆、备份）放在**安装目录下的 `data` 文件夹**（程序和数据在一起，想整体搬家就整个文件夹一起搬）；选「为所有用户安装」时，数据放在 `%APPDATA%\PodMates`。**卸载、重装都不会丢**（卸载时会问要不要删数据，默认保留）。程序启动时会自己找到数据在哪；开机自启、备份、导出导入、诊断包都跟着这个位置走。
> 有新版本时面板顶上会提醒（每天查一次 GitHub Releases）；程序**不会自动更新**，你下载新的安装包覆盖安装即可，设置全部保留。

## 二、第一次打开：设置向导

向导一共八步，每一步都能跳过，以后在面板里都能改：

1. **密码**：给面板设个密码。电脑上的面板窗口不用输；手机或别的电脑打开面板时要输。
2. **服务商**：机器人说话要调用大模型。选一家服务商（默认选好的是 DeepSeek，用官方的 `deepseek-flash`），粘贴 API Key，点「测试连接」（不耗额度）。
   不想把密钥存在程序里？可以改用环境变量，见第四节。
3. **角色**：选一个角色模板作为第一个角色（推荐「温和版群友」「翻译」「群聊总结与答疑」），也可以先跳过。
4. **用户卡**：她该怎么称呼你。「用户」是系统里固定的一张人物卡（装好就有，管理员、态度「亲近贴心」，名字等都空着），这一步把它填上：名字、身份（她妈 / 她爸……）、她怎么叫你（可以填多个；选了「她妈」「她爸」会给出常用称呼可以点选：妈、妈妈、老妈、母上、母上大人 / 爸、爸爸、老爸、父上、父上大人），以及可选的各平台账号。这里填的身份和称呼会写进这张卡上「全体角色」那套关系方案（关系按你填的来，「女儿」只是模板里的默认说法，不是固定设定）：人设文字里写 `{{用户}}`，替换成这张卡的名字，规则和 `{{平台}}` 一样，模型只看到换好的结果。多个称呼拼进人设成「称呼：妈、妈妈、母上……，随场合换着叫」。可以跳过；名字没填时，人设里含 `{{用户}}` 的整句和这张卡生成的那段都不出现。每个使用者的特殊性都只填在这张卡里，程序对任何具体的人没有特殊处理。界面上凡是列出人物的地方，这张卡显示成「用户 · 名字」、带「用户」徽标、排在最前面；它不能删，其余内容都能改，全表只能有一张。
5. **记忆**：她会按眼下的话题想起「意思相关」的旧事，靠一个在本机运行的小模型。向导按你电脑的内存推荐：内存 ≥ 16 GB 推荐效果最好的 GTE（要下载约 340 MB，一键完成），否则用随安装包带的小模型（不用下载）。
6. **平台**：QQ / 微信 / Discord，要哪个开哪个（更多平台在「账号」页里）。
7. **账号**：按平台添加机器人账号（第十一节有逐步说明）。
8. **完成**：可顺手打开「开机自启」「后台运行不弹黑窗口」。

向导以后还能在 **设置 → 关于 → 重新运行设置向导** 再走一遍。想先看看效果、不连任何账号：用 **「体验」** 页（第十二节）。

## 三、日常使用

- **托盘图标**（任务栏右下角，蓝色对话气泡）：双击打开面板；右键可以「启动/停止机器人」「退出」。
- **同一份数据只会有一个程序在运行**：程序一启动先取一个跟数据目录绑定的系统互斥体，取不到就说明已经有一个在运行（哪怕两个几乎同一秒启动，比如安装程序装完自己打开一个、你的部署脚本又启动一个）——后来的这个把已开的面板调到前面（开机自启、定时任务拉起时带 `--background` 不调），前一个刚好在启动、面板还没起来就多等它几秒，然后退出，不起机器人、不碰 NapCat 和微信。前一个崩溃或被强行结束，系统会自动放掉这个互斥体，下一次启动照常能起来。不同数据目录的两份互不影响。
- **关掉面板窗口机器人照样在跑**。要彻底关，右键托盘图标 →「退出」（会连账号的 NapCat 和 QQ 一起关）。
- **NapCat / QQ 独立运行，程序重启、装新版 QQ 不用重新登录**：程序拉起的 NapCat 不依附程序的进程，输出写进数据目录的 `napcat-logs\<QQ号>.log`（读完且超过约 24 MB 就自动清空；上一轮的留成 `.log.1`）。程序崩溃、被强行结束、被重新拉起、装新版时，NapCat 和 QQ 继续挂着。程序再启动时，先看这个号原来的 NapCat 还在不在、连不连得上、登录的是不是这个号：都满足就直接接回去（日志页 NapCat 类别会写「接回了已在运行的 NapCat，QQ 没有重新登录」），二维码、被踢下线、风控这些提示照常从日志文件里认；任何一条不满足，才像以前一样清掉重开，日志里写明原因（没有在运行的 NapCat / 连不上 / 登录的不是这个号 / 在别的文件夹或别的端口起的）。只有你明确要关的时候才会停它：面板上停止这个账号或停止机器人、托盘「退出」、卸载。账号被停用、删除或改成「不托管 NapCat」后，下次启动会清掉它上一次留下的 NapCat。第一次从旧版升到这一版时，旧版的 NapCat 是从管道里起的，装完可能还要扫一次码；以后装新版就不用了。
- 面板各页：

| 页面 | 干什么 |
|---|---|
| 总览 | 运行状态、各账号在线情况、今天用量、最近动态 |
| 消息 | 看各群**和私聊**的消息（左边可按「全部 / 群聊 / 私聊」筛选，每个私聊对象一项并标明平台；已配置但还没收到消息的群和私聊也会列出来，显示「暂无消息」；私聊记录只用来显示和手动接管，不占群聊的上下文）；用某个角色手动发言；点某条消息「让她回」；撤回她上一条；影子模式的「本来会说」也在这 |
| 账号 | 添加/启停各平台账号；扫码登录；改昵称头像签名群名片 |
| 角色 | 每个机器人人物：人设、给守门员的一句话摘要、插话力度、各项行为设置、QQ 群名片；可以「从模板新建」（他对不同的人是什么态度，在「人物」页各人物卡的关系方案里定） |
| 排班 | 同一个账号在不同群、不同时段、不同日期当哪个角色（第六节） |
| 人设 | 模块拼装（拖动排序、开关、编辑）、整体视图（实际发给模型的完整文字，可复制）、历史版本、试聊、构型库 |
| 人物 | 人物卡（各平台账号、关系方案——身份 / 称呼 / 态度、她知道的事、管理员、「用户」标记）、分组、态度四层 |
| 群 | 群档案（一句话说明这是什么群）、本群开关与插话力度、记忆开关、定时消息 |
| 记忆 | 人物备忘、群前情、群梗、文件片段；看来源消息、编辑、删除、审核；语义回忆（开关、向量模型）；记忆空间；导入以前的聊天记录 |
| 体验 | 不连任何账号的模拟群（第十二节） |
| 日志 | 实时日志，守门员每次插不插都有理由，可按类别筛选 |
| 用量 | 按天、角色、群、用途、模型、平台统计；缓存命中率、平均每条回复的 token、趋势图；导出 CSV（第十节） |
| 设置 | 模型与接口、全局默认、平台、访问与安全（密码、手机、Tailscale）、系统（含诊断包、新版本检查）、数据与迁移、关于 |
| 指令 | 自定义指令：群里有人这样说，就做这件事（触发条件、动作、谁能用、生效范围、冷却时间），见第十七节 |

**设置是分层的**：全局默认 → 平台 → 角色 → 角色在某平台 → 群 → 角色在某群。没单独改的项沿用上一层；
每一项旁边写着「继承：××」或橙色的「已改」，改过的可以点「恢复继承」。常用的在外面，少用的收在「高级设置」里。每项都有默认值，不碰也能正常跑。

**管理指令**（在群里 @她 + 固定说法）：

| 说法 | 作用 |
|---|---|
| 闭嘴 / 闭嘴30分钟 | 在本群不说话（默认 30 分钟） |
| 恢复 | 解除闭嘴 |
| 换温和版群友 / 换人设 温和版群友 / 换人设 2小时 | 临时换成某个角色（或某套人设），可带时长（「2小时」「30分钟」），不带就到当天结束；到期回到排班的安排。名字对不上任何角色或人设时，当普通聊天回 |
| 换回 | 取消临时换，马上回到排班的安排 |
| 插话开 / 插话关 | 本群主动插话开关。设的是「**收到指令的这个账号在本群**」：不管谁在岗都生效，换班后照样有效，同群别的账号不受影响，重启后还在；比面板上所有设置都优先。面板「群」页最上面会写出来，点「清除」就恢复按面板设置 |
| 插话力度 1~5 | 1 很少 … 5 话痨（作用范围同上） |
| 状态 | 报告闭嘴、插话、人设、今天用量 |
| 撤回 | 撤回她上一条（微信不支持） |
| 忘掉 某人/某事 | 删掉相关记忆。要至少 2 个字，太短她会反问你要忘什么；删之前自动备份，管理员可以在 记忆 页「撤销刚才的重置」 |
| 忘掉我 | 任何群友都能让她删掉关于自己的记忆（管理员的人物卡例外，只能在面板里改） |

**管理指令收到就立刻办**：不排进回复队列，也不受「两次回复最小间隔」限制——队列里压着别的 @、或者正在等间隔时，指令照样马上生效，确认回复也马上发，署的是**换完之后**的角色。队列里还没回的其他 @ 之后都由新角色来写；合并 @ 时，指令那条不算一次「被叫到」；「闭嘴」之后，这个角色还没发出的回复（排队的、正在写的）一律作废。自定义指令也是收到就办。指令的回复不占「两次回复最小间隔」的计时。

谁能用哪条指令在 **设置 → 全局默认 → 权限** 里设（默认只有「我」，即人物表里勾了「管理员」的人）。没权限的人发指令，她用自己的方式拒绝。

**指令总表**：在群里 @她 说「指令」或「帮助」，或者私聊她说「指令」「帮助」，她会回一份**你能用的**指令清单（第一行是「你能用的指令：」，每条一行：说法加一句用途）。群里按「管理指令权限」只列你有权限的；用户卡本人私聊时列私聊指令；没有可用指令的人，回「你在这里没有可用的指令」。面板 设置 → 全局默认 → 权限 里「管理指令权限」旁边有同一份总表（全部指令，标明在哪说、谁能用）。

**插话上限**（设置 → 全局默认 → 插话，叠加起来取最严的）：「每小时插话上限（整个账号）」默认 360，是整个机器人账号在所有群里加起来的数——平台风控是按账号算的；「每小时插话上限（每个群）」默认 90；「每天插话上限（每个群）」默认 600；冷场开话题每群每天最多 12 次。发一张表情包也算一条发言。

## 四、服务商与模型

面板 → **设置 → 模型与接口**。

- **默认**：主模型、守门员、记忆整理、看图都用 DeepSeek 官方的 `deepseek-flash`（官方别名，永远指向最新的 Flash，不用跟着改版本号）。这四处可以分别选服务商和模型。
- 两个页签：
  - **第三方服务商**：内置几十家（数据来自 [models.dev](https://models.dev)，MIT 许可），下拉选一家、填上密钥就能用。点「联网更新服务商目录」可以刷新清单。
  - **自定义 API**：自己的中转站、本机的 Ollama / LM Studio、公司内网网关……填接口地址和协议即可。支持三种协议：OpenAI 兼容、Anthropic、Gemini。
- 已配置的服务商以卡片列出：名字、密钥状态、连通状态点（绿 = 上次测试通；红 = 没通；灰 = 没测过），可测试、编辑、删除。
- **密钥怎么存**：存在本机数据里，**用你的 Windows 账户加密**（DPAPI），不进安装包、日志、诊断包；导出数据包默认不带。也可以**不存**：把「环境变量名」填上（比如 `DEEPSEEK_API_KEY`），密钥留空，程序会去读这个环境变量，面板上会写明密钥是「来自环境变量 XXX」。
- **选模型**：模型框旁的「选择…」会向服务商拉取当前的模型列表（拉不到就用内置目录里的清单），带「能看图」「可思考」标记；也可以直接手填模型名。模型不在所选服务商的列表里时，面板会在这一项下面提示（不拦保存、不改设置）。
- **思考强度**：不同服务商的写法不一样（智谱和 DeepSeek 用 `thinking` + `reasoning_effort`；OpenAI 系只认 `reasoning_effort`；Anthropic 用 `thinking` + `output_config.effort`；Gemini 用 `thinkingConfig`），程序会自动对应；不认识的服务商一律不发思考参数，需要时在服务商卡片里改「思考强度写法」或写「额外请求参数」。**面板里的选项按这个模型真正支持的档位列**（服务商目录里有这个模型的资料才限制，没有的照旧给全套）：比如 GLM-5.3 系列是强制思考、不能关，只给「低 / 高 / 最高」，说明里写明「不选就等于最高」，发出去的永远是官方支持的 `low` / `high` / `max`，不再发 `medium`，也不再「什么都不传」。以前存的值只改模型不支持的：「中」换成最接近的「高」，设成「不思考/默认」而模型不能关的保持不传、面板上显示成「最高（默认）」，手动设的「高」「低」这些不动（存的值本身不改，发请求和显示时换算）。**守门员、看图、记忆提取、主回复的思考强度默认都是「高」**；用的模型不支持「高」时，取它支持的档位里最接近的。
- **看图**：设置 → 模型与接口 → 打开「看图」，并给「看图模型」选一个能看图的（DeepSeek 官方文档说 `deepseek-flash` 支持图片输入）；每张图多一次模型调用。**微信也能看图**：收到图片时，程序把图下载下来（先用 wxauto4 的 `ImageMessage.download()`，不成再右键「复制」读剪贴板；微信 4.1.15 在聊天里把图片显示成「图片」两个字，也照样认得出来。下载本身没有超时参数：独立窗口方式排在微信线程的队列里；主窗口轮询方式放到单独的下载线程里，两种办法加起来最多等 25 秒，不会把收消息卡死），交给同一个看图流程，在上下文里写成和 QQ 一样的「[图片：……]」；开关、看图模型、用量上限都和 QQ 共用（每条消息最多描述 2 张；看图关着时只写前 3 个占位）。**微信里群友发的表情也能看**（包括从相册发的动图，微信会把它变成表情）：表情类消息（type 是 emotion，或内容是「动画表情」这类）不走下载：微信里表情和图片的处理方式不同，表情点不开大图、也没法另存，所以程序**截聊天里这条表情所在的那一块**交给同一个看图流程，看完在上下文里写成「[表情：……]」，让她知道这是表情不是照片（截下来后裁到表情本身，头像去掉，群聊里昵称那一行和表情之间隔着空白时也去掉；动图连截三帧一起给看图模型看，三帧一样就只交一张）；截之前会确认那一块露着的是这条消息所在的窗口（拿不到那个窗口就不看）、够大、在显示器里，微信自己的菜单、别的聊天窗口盖在上面都不看；截之前还会先关掉盖在那块上的微信自己的小菜单（只对那个菜单发 Esc 或关闭，不碰主窗口），关不掉、或者被别的窗口盖住就不截，截不到也只写「[表情]」，日志记一笔、不重试；另外，微信读完消息会在最新一条别人的消息的头像旁边留一个「@某某／拍一拍」小菜单，PodMates 每次读完消息都会对这个菜单发一次 Esc 把它关掉（同样只发给菜单，不碰主窗口；关不掉就留着，记一条日志）；开着「移到屏幕外」时先把微信窗口移回来、截完再移出去，不抢前台焦点；截屏来的表情按画面指纹（dhash）记「同一张图只看一次」（指纹按裁出来的第一帧算），截屏的背景和位置有点差别也认得出是同一张；
QQ 的自定义表情和动图（NapCat 的 image 段带 `sub_type` 为 1 或 `summary` 里有「表情」）也写成「[表情：……]」，商城表情（`mface`）照旧只写「[表情]」、交给学表情包。新开关**群友发的表情也看**（设置 → 模型，`vision_stickers`，默认开，作用范围和「看图」一样，只在「看图」开着时有意义）：关掉后微信表情不截屏、QQ 的表情图不看，都只写「[表情]」，普通照片照常看；表情每张多一次看图调用，关掉能省用量。微信的表情只看不学（不交给学表情包）。**同一张图只看一次**：看图结果按「图片内容 + 看图模型」记下来（所有平台），同一张图再出现时直接用，不再调模型（截屏来的微信表情按画面指纹 dhash 记，指纹完全相同才算同一张，截屏的背景和位置有点差别也认得出）；换了看图模型会重看；只记成功的描述；和聊天记录一起清理（见下），没有单独的开关。下载失败、超时（25 秒）照旧写「[图片]」（表情写「[表情]」；认出是图片、但没下载的也一样，不会留下光秃秃的「图片」两个字），日志记一笔，不重试；看图关着或没配看图模型时不下载、也不截表情。下载下来的文件读进内存后立刻删掉。私聊里的图片也一样会被看。
- **备用服务商**：主服务商出错（余额不足、限流）时自动切到备用，默认关闭。
- **新模型提醒与替换**（只提醒，**永远不自动换**）：设置 → 系统 →「多久查一次新模型（小时，0 = 不查）」，默认 24。到点问一遍你配过的各家服务商（在任何一层设置里被主模型、守门员、记忆提取、看图或备用用到的）现在有哪些模型：先问服务商，问不到就联网更新一次内置目录再用目录里的清单；不经过搜索服务、不花 token。**第一次只记不提醒**，之后新出现的才算新模型；启动后也按上次检查的时间算，不会一启动就查。
  - **同系列**：把模型 id 里的版本数字去掉后一样、新版本号更大，才算同系列（例：`glm-5.3-flash` → `glm-5.5-flash`）；日期后缀不看，「4-5」当 4.5；版本数字不止一组的（如 `qwen3-235b`）拿不准，不算同系列。你在用的模型出了同系列新版本，就提醒你一次（面板总览一条未读通知，再私聊用户卡本人），文字里写明旧、新、用途，以及按目录比出的能力差别（能不能看图、能不能用工具、能读多长，目录里没有资料的不写）。不是同系列的新模型不提醒，只在那家服务商的卡片下面列出「这家新出的模型」（带发现日期）。
  - **替换**：面板服务商卡片上的「一键替换」，和私聊指令走同一套：先用新模型真调一次确认连得通；要换的地方里有看图，还要确认新模型真能看图（读一张小图）；不通过一处都不换，把原因告诉你。通过后，在**所有作用域**（全局、角色、平台、群及其组合）里，把用这家服务商、且模型等于旧模型的主模型、守门员、记忆提取、看图都换成新模型，备用模型等于旧模型的也换；换完记一条日志。思考档位沿用「保存的档位新模型不支持时换成最接近的」。基本调用测通、只有看图没过时，可以点「只换能换的」（看图仍用旧模型）；新模型能看图、看图那一项没在用旧模型时，有「看图也换」。「暂不换」过「回『不换』后多久再提醒（天）」（默认 7）再提醒一次，「一直不换」就不再提；被设成暂不换、一直不换的模型列在卡片下面，各带「撤销」。「现在检查新模型」立刻查一次。
  - **私聊指令**（只认用户卡本人，别人说同样的话照常聊天）：**换**（按最近一条提议替换）、**换能换的**、**看图也换**（看图原来关着，不替你打开，只提醒一句）、**不换** / **不换 30 天**、**一直不换** / **别再提**、**换模型 旧 新**（把这家服务商上的旧换成新，新模型要在那家的模型列表里）、**查更新**（立刻查一次新模型和新版本，新版本照旧只提醒）。没有待回复的提议时，「换」「不换」「一直不换」当普通聊天。
- **代理**：访问海外服务商和海外平台（OpenAI、Anthropic、Gemini、Telegram、LINE、YouTube、X、Discord……）国内一般要代理：在「模型」里填代理地址（如 `http://127.0.0.1:7890`），再在每个服务商卡片/账号上勾「使用代理」。

## 五、角色模板与构型

面板 → **角色**页：上半部分是「我的角色」，**下半部分常驻着「角色模板库」**（28 个模板，向导里也有）。按六个类别分组，每张卡片有名字、一句话简介和「用这个」按钮；点卡片上的「展开预览」能看人设全文；上面可以按类别筛选、按名字搜索；手机上也一样用。页顶的「从模板新建」按钮会直接滚到模板库。按类别放着：

- **原创角色**（1 个）：海豚娘（对线不设限，嘴毒，挂「群友性格」，自带「构型171」）。她的外壳后面挂着共用模块：群友性格、拉康派、AI身份、构型171、说话风格、边界；七个哲学模块（尼采、黑格尔、阿尔都塞、巴迪欧、海德格尔、谢林、荷尔德林）也还在共用模块里，可以单独挂到别的人设上。
- **娱乐陪伴**：温和版群友、捧场开心果、冷面段子手、深夜聊天搭子。
- **学术讲解**：经济学教授、商学院教授、政治学教授、精神分析理论家、哲学教授、历史学者、社会学者、心理学科普、法学科普、数理与编程老师、文学评论家。
- **生活健康**：营养师、健身教练、作息顾问、情绪陪伴（不做治疗）。
- **实用工具**：翻译、写作润色、编程助手、学习规划、群聊总结与答疑。
- **游戏主持**：跑团主持、谜题主持、狼人杀法官。

选一个模板就**复制**成一个新角色，之后随便改。人设只在第一次从这个模板建角色时复制一份；之后再从同一个模板建角色，直接用已有的那份人设，不会再多出一个同名的。想要改过的变体，到人设页点「复制一份」（副本自动加后缀 2、3……，改副本不影响原件）。每个模板有自己的内核模块；医疗、营养、法律、心理一类模板都写明「以科普和给方向为主，不下诊断，大事找执业人士」；除「原创角色」外，模板默认不带构型。海豚娘的外壳里写的是「你是「{{用户}}」的女儿」，按人物表里「用户」那张卡的名字显示。

想放自己的模板，在数据目录里建一个 `templates` 文件夹，照 `assets/templates` 里的格式写 `.md` 文件；同一个模板 id 两边都有时，以你的为准。本地模板不进安装包，也不会随升级被覆盖。

不想去数据目录里手工建文件，可以直接在面板上操作（手机上也行）：模板卡片上的**「复制到本地模板」**会把这个模板原样写成数据目录 `templates` 文件夹里的 `local-<模板 id>.md`（自带外壳的模板会把外壳原文写进正文），提示里会给出完整路径；本地模板的卡片上有「本地」徽标和**「编辑」**按钮，点开是整个文件的全文，保存前会检查格式（至少要有 `id`、`name`、`category`，而且不能改 `id`），不合格就提示哪里不对、不保存；用「复制到本地模板」复制出来的，同 id 的自带模板还在时还有**「恢复成自带的」**，确认后删掉那个 `local-<id>.md`。自己放进去的本地文件只能编辑，不提供删除。已经建好的人设不会跟着变：想让角色用上新内容，到「人设」页改，或者删掉那份人设后再从模板新建。

**承认是AI（总开关）**：「总览」页最上面有一个开关。开：被问是不是AI就认（人设里的「AI身份」模块照常出现，各模板里「你是AI，被问就认」这类句子也照常出现）；关：这些都不出现，提示词里不再写「是AI」。每个角色在「角色」页还有一个三档选项：跟随总开关（默认）/ 开 / 关，单独设了开或关的不受总开关影响；某个平台、某个群里也能单独设（和别的设置一样分层：角色在群 → 群 → 角色在平台 → 角色 → 平台 → 全局）。新装默认开。自己写人设时：模块上可以打开「受『承认是AI』开关管」，文字里写 `[[AI|这段话]]` 的部分也跟着开关走。

聊天记录里她自己发的话，给守门员看时标成「她（自己）」。全部模板文字见 [模板文本.md](模板文本.md)。

**构型库**：安装包里只自带海豚娘用的「构型171」。要用别的构型，到 **人设 → 构型库 → 导入构型文件**，选构型 JSON 文件（可以一次选几个）。导入时只取 `id`、`coreProposition`、`realityExpansion`、`characterTendency` 这几项，文件里别的内容一律丢弃，不会进程序。

人设里的「QQ群」「QQ纯文本打字」「QQ昵称」这类字样会**按当前平台显示**（QQ群 / 微信群 / Discord服务器……）；「不用 Markdown、列表、标题、加粗」这条格式要求只挂在不渲染 Markdown 的平台上。

### 角色标签与人物卡的「关系方案」

同一个人，不同角色可能该有不同的关系：海豚娘叫他妈，换上岗的「商学院教授」就该叫他同学或学生。所以人物卡上的**身份、称呼、态度**不再是死的一份，而是可以存**多套「关系方案」**。

- **每套方案**有：方案名（比如「女儿」「老师和学生」）、关系（她把这个人当作什么人，写进提示词的小标题和「是……」那句）、称呼（可以填多个）、态度，再加上**作用范围**：「全体角色」/「按标签」（可选多个标签）/「指定角色」（可选多个）。
- **角色标签**：在「角色」页给角色打标签。从模板新建的角色，默认带上模板的类别作为标签（「原创角色」「学术讲解」「实用工具」……）；升级时已有的角色，认得出来源模板的也会补上。
- **某个角色面对这个人，用哪套**：指定角色 > 按标签 > 全体角色；同一优先级里命中好几套，取人物卡上排在前面的（人物卡里有「↑ ↓」可以调顺序），并且会提示有冲突。都不命中，用人物卡自己的那套（跟着排在最前面的「全体角色」方案走）。
- 管理员权限、聊天记录里「〔表名本人〕」的认人，和方案无关，不变。
- 「角色」页能看到每个人对这个角色当前用的是哪套方案、来自哪条规则。角色以前那种「对某人另设态度」的覆盖没有了——要为某个角色另设，就在那个人的卡上加一套「指定角色」的方案，这样态度只在一处决定。
- **从旧版升级**：人物卡上原来的身份、称呼、态度，原样成为一套叫「默认」的方案（全体角色）；角色上原来对某人的态度覆盖，并入成那个人卡上的一套「指定角色」方案（身份、称呼照抄默认那套），然后清掉角色上的覆盖。所以升级前后，任何角色看到的人物卡一字不差。

## 六、排班：同一个号在不同群、不同时段当不同角色

面板 →「排班」。

- **规则** = 若干条件 + 一个结果。条件都可以不填（不填就是不限）：平台、账号、群（可多选）或群分组、日期区间、星期、每天的时段（可以跨午夜，比如 22:00 到 02:00，过了 0 点那一截算前一天的星期和日期）。
- **结果**：固定一个角色；或在几个角色之间轮换（按顺序或随机，按天或每隔几分钟换）。随机也是「一段时间内固定」，不会每条消息都换人。
- **优先级**：从上往下判定，先命中的算，拖动排序；也可以点「按具体程度自动排序」（指定日期 > 星期加时段 > 只限星期 > 每天时段 > 不限）。都没命中就用账号的「默认角色」（账号页设）。
- **群分组**：「群」页上方建分组，在群设置里把群加进去，规则里可以直接选整组。
- **看效果**：「现在是谁」列出每个群此刻是谁、下次几点换成谁；「排班视图」按周或按月看；永远轮不到的规则、过期的规则、没有任何角色的时段会在页面顶上提醒。
- **换班**：可以让新角色在群里打个招呼（默认关），QQ 群名片可以随角色自动改（默认关）。头像和昵称是整个账号共用的，不随群或时段变。
- **记忆默认按群、按私聊隔离**：每个群、每个私聊得来的记忆（人物备忘、群前情、群梗、「记住」的事、文件片段、群风格画像、表情包）只在那个群、那个私聊里用，不会串到别的群；语义回忆也只在当前群 / 私聊的范围里找。私聊按「哪个账号 × 哪个人」各自一份；人物备忘还按角色分开记（换了角色，群前情、群梗照样接得上）。
- 想让几个群（或私聊）共享记忆，就在「记忆 → 记忆空间」建一个空间，把它们（也可以按角色、按平台）绑在一起；自定义空间优先于默认的隔离。文件片段按「文件片段」这个种类选空间；几个群的风格画像绑到同一个空间时共用一份。人物表（人物卡、称呼、态度）不是记忆，所有群通用。
- 从旧版升级时，原来按角色共用的人物备忘会按每条记录的来源拆回各自的群；私聊里存下的，能确定是哪个账号 × 哪个人才认领，认不出来源的一条不删，放在「记忆」页的「待认领」空间里，由你决定去处。

### 记忆怎么整理、怎么拼进提示词

- **群里发生的事分层合并，写成后不改**：每 50 条消息（「每多少条消息整理一次记忆」）整理一段，叫第一层——不设字数，只写以后用得上的事，闲聊寒暄不写，事多就长、事少就短。每 5 段并成上一层，这一层最多写「所并各段**实际字数**之和 × 倍数」字（倍数在 设置 → 全局默认 → 记忆，默认 0.7，可选 0.5 / 0.6 / 0.7 / 0.75 / 0.8，也可以自己填；算出来不足 30 字时按 30 字算，免得并得太短读不懂）。并的时候要求：每件事写明谁对谁做了什么；后来又变了的，写变了以后的样子并写一笔怎么变的；人名照原文，不写感受，不添原文没有的事。写成的单位不再重写，改了倍数只影响以后新并的。每个单位记着层级、覆盖的消息范围和时间范围、这一段里说话和被提到的人。
- **不漏**：拼给模型的最近原始消息，至少是最近「群上下文条数」条，并且一直往前带到最近一段前情结束的地方——群里每一条消息不是在前情里，就是在原始消息里。整理没成功的一段会隔一会儿重试，连着失败 3 次就把原话存成一个第一层单位，不会丢。
- **怎么摆**：先用写好的最粗一层盖住全部较早的历史；空间够，就从最新往前，把单位换成覆盖同一范围的下一层，越新越细，换不下就停；空间不够，从最早的单位开始让。按时间先后排，每个单位标出时间范围（比如「10 月 20 日—10 月 24 日」），抬头是「【这个群以前的事】（按时间先后，越早越概括）」。
- **人：印象 + 原始备忘**：备忘默认永久留着（设了「记忆保留天数」时按那一节处理），带日期和来源（本人说的 / 别人说的 / 她推测的）。每个人在每个记忆空间里还有一段「印象」，写他现在的情况；当他的备忘被挤出「最新 100 条」（设置里「每人最多带几条最新备忘」，默认 100）时，挤出去的并进印象——原印象里的事除非被后来的事实推翻一条不丢，被推翻的写一笔怎么变的，本人说的和推测的分开写，不设字数。同一个人在几个角色的空间里有同样的备忘时，印象只更新一次。「记住……」要求记住的不并进印象，每次原样带上。每个在场的人，提示词里带：印象、最新 100 条备忘、他要求记住的。
- **按人取回旧记录**：已经被并进上层、眼下没原样摆出来的第一层前情，和在场的人眼下没摆出来的旧备忘，由程序按编号打分（这条消息里提到的人 +2，最近原始消息里说过话的人 +1，她自己不算），分高的先取、同分取较新的，按时间排，放在「【和眼下这些人有关的旧事】」一小节；最多占记忆一节空间的 75%、一次至多 1000 条（这两个数是 设置 → 记忆 里的高级设置「取回旧记录最多占记忆一节的百分之几」「取回旧记录一次至多几条」，全局和单个群都能调）。空间紧时先后是：在场的人的印象和他要求记住的（必放）→ 最粗一层前情 → 在场的人的最新备忘（放不下先让这次没被提到的人的、同一相关分里从最早的让，让掉的进取回的候选）→ 取回 → 剩下的给前情从新往旧细化。最粗一层是群里旧事唯一的完整覆盖；备忘的内容前情里大多也有，人的现状又有印象兜着。群梗和语义回忆想起的旧事也算在这一节的空间里（含「记忆最多带多少」），超出时按上面的先后少放；印象和「要求记住的」照旧必放。
- **空间多大**：记忆一节不设固定上限，用的是「模型能读多长」减去回复长度和人设、人物表、原始消息等其余部分。「模型能读多长」：你在 设置 → 模型与接口 → 编辑服务商 里填的优先；没填就取服务商目录里报的、报错里写明的、被拒后记下的里最小的；都没有按 1M；成功发出过的最大请求作为底。请求因为超长被拒，程序会记下报错里的上限，按新上限重新摆一次再发一次，这次回复不丢。想省用量，在 设置 → 全局默认 → 记忆 里填「记忆最多带多少字」（默认 0 = 不限），超出时按上面「空间紧时」的先后少放。
- **保留天数**：「记忆保留天数」（设置 → 全局默认 → 记忆，默认 0 = 永久，可以按群单独设）管旧的备忘、前情、群梗和文件片段。「保留天数也让人物备忘过期」默认开：人物备忘也按天数过期，过期后用这个人剩下的备忘重写他在这个记忆空间里的印象（做法和面板里删掉备忘后一样），一条都不剩就清空印象；关掉就只清其余的，人物备忘不过期。「本人要求记住」的、风格画像、表情包和印象始终不按天数清。另有「聊天记录保留天数（0 为永久）」（设置 → 系统，默认 30，0 = 永久不清）：管聊天记录和看图缓存，和记忆保留天数是两个设置。
- **群梗**在这个群的全部群梗里按关键词找，不只看最新的。
- **忘掉和重置**：「忘掉我」删掉这个人的备忘和印象，以及前情里含他的单位（连同覆盖它们的上层）；「忘掉××」和「重置记忆」同样处理，删掉的备忘属于谁，就用这个人剩下的备忘重写谁的印象（不看印象里有没有同样的字）。删掉的上层之后由剩下的下层重新并。三种都先备份，能在 记忆 页「撤销刚才的重置」。**记忆页**可以看、改、删前情单位（带层级和时间范围）和人物印象；改过的单位，覆盖它的上层之后照改过的重写。

## 七、语义回忆

她除了记得在场的人、群前情、提到的群梗，还会按眼下聊的话题想起「意思相关」的旧事（没提到当事人、也没碰上关键词也能想起来）。同一条记忆只放进去一次；语义取回的旧备忘和普通备忘一样带日期。

- 开关在「记忆 → 语义回忆」，默认打开；每个记忆空间还能在「记忆 → 记忆空间」最下面单独关。
- **默认用本机小模型**（BGE small 中文，随安装包，不调接口、不花钱，内存多占约 50 MB）。电脑内存 ≥ 16 GB 时，向导会推荐一键下载效果最好的 GTE multilingual base（约 340 MB，多占内存约 600 MB）。
- 也可以改用接口（API）：选「接口」，挑一个预设（推荐硅基流动 Qwen3-Embedding-4B，约 0.14 元/百万 tokens），填 API Key。
- **向量过期会自动重建**：换了模型或来源、有记忆还没算过向量（导入、恢复、上次没算成）时，程序启动时和运行中每隔半分钟检查一次，发现就自己在后台补算，不用手动点；页面上显示状态和进度（也留着「一键重建」，想马上开始或全部重算就点它）。重建不挡回复，期间语义回忆只用已经算好的那部分，不混用新旧模型。本机模型还没下载好、接口还没设好、用量硬上限生效时不硬试，页面上写明原因，只记一条警告，条件好了再自动补；重建失败的话隔一阵再试，越试隔得越久。
- **模型下载不下来（国内网络）**：程序会依次试 ModelScope（魔搭，国内能直接下）、Hugging Face、hf-mirror。都不行时手动下：
  1. 打开魔搭网站，搜模型名（比如 `onnx-community/gte-multilingual-base`），进「模型文件」，下载 `onnx` 文件夹里对应的文件（列表里写着用哪个文件，比如 `model_quantized.onnx`）和根目录的 `tokenizer.json`。
  2. 把 onnx 文件改名为 `model.onnx`，和 `tokenizer.json` 一起放进页面上写的文件夹（`数据目录\models\<模型名>`）。
  3. 回到页面刷新，显示「已下载」就能选了。
- 「试一试」可以输入两句话看相似度，用来判断要不要调「相似度门槛」（设置 → 全局默认 → 记忆 → 高级）。默认 0 表示用每个模型标定好的门槛。

## 八、读文件

**默认关闭。** 设置 → 全局默认 → 文件 里打开「读文件」（也可以在某个群的设置里单独开关）。

- **什么时候读**：默认「被叫到才读」——有人 @她，或回复那条文件消息时才读（@她但没回复文件时，取这个人 15 分钟内发的最近一个文件）；也可以选「收到文件就读」。
- **读到的怎么用**：文件下载到临时位置，抽出文字后**立刻删掉原文件**；文字切成片段存进记忆（建向量，以后聊到相关内容能被想起），这一次回复也会带上节选。可选「保留原文件 N 天」，并设总容量上限，满了自动删最旧的。
- **限制**：单个文件大小上限（默认 10 MB）、单次读取的 token 上限（默认 6000）、允许的格式（PDF、Word、Excel、PowerPoint、文本与代码、图片，默认前五种）。**只解析，不运行**：不执行宏、不打开链接，压缩类文件有解压后体积上限。
- 目前 QQ、Discord、Telegram、LINE 的文件消息能读；微信和评论区类平台不支持文件。扫描版 PDF（没有文字层）读不出文字。

## 九、回复语言

设置 → 全局默认 →「回复语言」：默认中文；角色、平台、群三层都能单独设。可选 English、Français、Deutsch、Italiano、Русский、日本語、Español、한국어、العربية、فارسی、Português 等，另有「跟随对方的语言」。

## 十、用量

用量页除了按天/角色/群/用途/模型/平台统计，还有：**缓存命中率**、**平均每条回复的 token**、**思考 token**（接口返回了才有）、**缓存写入**（接口返回了才有）、**趋势图**，可以**导出成 CSV**。只统计 token 和次数，**不换算成钱**（各家价格和优惠不同，以服务商账单为准）。

## 十一、各平台的开通与真号联调（照着做即可）

> 面板「账号」页里每个平台都有同样的分步引导，下面是摘要。

### QQ（扫码登录）

1. 面板 → **账号** → QQ 那一栏打开开关。
2. 点 **「准备 NapCat」**，二选一：
   - **用现有的**：如果你已经有 NapCat 的文件夹（一键包或 Shell 版），在「方法二」里填它的路径，点「使用这个文件夹」。已经登录过的号可以免扫码快速登录。
   - **自动下载**：点「从官方 GitHub 下载」（约 36MB）。这种方式要借用电脑上装的 QQ，没装的话先到 QQ 官网装一个。
3. QQ 栏点 **「添加」** → 填机器人小号的 QQ 号 → 选角色 → 保存。**建议用专门的小号。**
4. 点这个账号的 **「启动」**。登录过的号会直接上线；没登录过的会出现 **「扫码」** 按钮 → 点开 → 用**手机 QQ（机器人小号）**扫 → 手机上点确认。
5. 在群里 @她 说句话，看她回不回；**消息** 页能看到群消息；**日志** 页能看到守门员判断。
6. 二维码扫不出来时：账号设置里有 NapCat 的「备用网页」地址，浏览器打开也能登录。

> NapCat 的许可证是自定义的「有限再分发许可证」，**禁止商用**，且不明确允许打进第三方安装包，所以本程序**不带它**，由你从官方下载。请自己阅读并遵守它的许可证。

### 微信小号

1. **微信版本**：程序用 wxauto4 做界面自动化。wxauto4 自己没有写明确的版本范围，PyPI 上的说明只有一句「适用最新4.1.8」，所以程序按 **4.0 ～ 4.1.8** 当作它声明的适用范围（这个范围是我们按那句话定的）。每次连接微信时程序都会核对本机版本，面板「账号 → 微信」也会显示：绿色 = 在范围内，可用；蓝色「已验证」= 超出范围，但我们在真机上实测能用（目前是 **4.1.15**，用「主窗口轮询」收消息），措辞不会说成「不支持」；黄色 = 超出范围又没验证过（或太旧），很可能连不上或界面一改就失灵。后两种情况程序会**通知你**（每个版本只通知一次）：面板「总览」页挂一条「未读通知」；同时发消息给「用户」卡上填的账号（在所有在线账号里挑一个能联系到你的发，出事的那个账号除外：QQ 按 QQ 号，微信按秘密备注，Discord、Telegram 按 ID）；Windows 上还会弹托盘气泡。**通知只私聊你本人：按人物卡上你在这个平台的账号挨个试，微信上要切过去后确认打开的正好是你那个私聊才发，对不上就换下一个；都发不出去就只留在面板的「未读通知」里，绝不会发到群里**（面板那条通知的「怎么发的」只在真发出去以后写上平台）。建议在微信设置里关掉自动更新，免得它自己升到没验证过的版本。
   **wxauto4 新版提醒**：程序每天查一次 PyPI 上 wxauto4 有没有新版（「平台设置 → 微信」里可以关，默认开）。有新版就在「总览」和「账号 → 微信」提示，再私聊通知你一次，写明新版号和它声明适用到哪个微信版本；新版能覆盖更高的微信版本时会提示「可以把微信升到 X 了」。只提醒，**不自动升级**：要升级，先在账号页停掉微信账号，再点「账号 → 微信」里的「升级 wxauto4」（装到 `data\pylib`）；升级失败会自动回退到原来的版本并记日志；升级成功后重启程序才生效。
2. 在这台电脑上**打开微信，登录小号**。
3. 面板 → 账号 → 微信打开开关 → 点 **「下载组件」**（wxauto4，约 2MB，从 PyPI 官方下载，只需一次；它没有声明许可证，所以不随安装包分发）。
4. 点 **「添加」** → 在「监听的聊天」里填要她说话的**群名**（和微信里显示的一模一样），私聊就填好友备注、类型选「私聊」→ 保存 → 启动。
5. **秘密备注认人**：在小号的微信里，给你大号（和其他要认的人）设一个只有你知道的备注，然后到面板 **人物 → 对应人物卡 → 微信秘密备注** 填同样的备注。设好之前，微信里她认不出这个人。
6. **注意**：微信窗口要一直开着（可以被别的窗口挡住，别最小化、别关）；一台电脑只挂**一个**微信小号；微信不能撤回、不能由程序改昵称头像。
7. **身份绑定（防止拿大号当机器人）**：这台电脑上微信登录的可能是你自己平时用的号，所以微信账号**第一次启动时**，程序会读出当前登录微信的昵称和微信号，弹窗问你「这是机器人小号吗？」——点「是」才开始工作并记下这个号；点「不是」就不启动（先在微信里换成小号登录）。账号卡片上显示「已绑定：昵称（微信号）」。
   - **之后每次启动都核对**：登录的和绑定的对不上，就拒绝启动并提示「当前登录的是 ×××，不是绑定的机器人小号，已停止」；**运行中也会复核，而且是真的重新读当前登录的身份**（wxauto4 的 GetMyInfo 只返回连接时缓存的，读不出换号，所以每次复核都重新连一次微信窗口去读）：每次要切会话或发送时，如果距上次核对超过 60 秒，就在那一刻顺带复核（这时窗口本来就要被激活，不额外抢焦点；对不上就不读、不发）；一直没有这类操作时每 10 分钟单独复核一次；微信主窗口换了（退出再登录）立刻复核。发现换了号立刻停止监听、不再发言，并弹通知。
   - **核对依据**：优先用微信号（wxid）；读不到微信号才用昵称。只靠昵称时，昵称一改就当作对不上：停下，下次启动请你重新确认。
   - **换小号 / 绑定错了**：点账号卡片上的「重新绑定」，会清掉记着的身份并重启这个账号，按这会儿登录的微信重新问你。
   - **绑定时的额外保险**：读到的微信号、昵称如果和人物表里某个人的微信信息对上（人物卡的「微信号」、「微信秘密备注」、「微信」昵称），确认框里会出现醒目的警告「这是人物表里『×××』的号，确定要让机器人用它说话吗？」（是管理员的话加粗标红），**必须再确认一次才能绑定**，而且默认按钮是「取消」。没命中就只确认一次。
   - **人物卡上的两个微信字段，用途不同**：**「微信号」**（可填多个）只是上面这道保险：绑定微信账号时拿来对照，防止把你自己的号当成机器人；**「微信秘密备注」**才是微信群里认人的依据（界面自动化看不到发言人的微信号，只能看到你在小号里给他设的备注）。
8. **收消息方式**（设置 → 平台设置 → 微信「微信收消息方式」）：**独立窗口**是原来的方式（把每个监听的聊天拆成单独窗口）；**主窗口轮询**不拆窗口：隔几秒看一眼会话列表，哪个监听的聊天有新消息就切过去读，读完切回你原来打开的那个会话；发消息也在主窗口里完成（切到那个聊天再发，发完切回）。默认「自动」：微信版本在 wxauto4 支持范围内用独立窗口，超出范围（比如 4.1.15）用主窗口轮询；独立窗口方式失败了也会自动改用轮询并写日志。间隔见「微信检查新消息间隔」（默认 1 秒）。
    **往群里或私聊发消息前，都先确认打开的正好是那个会话，对不上就不发，日志里记一笔**：先按名字精确切换，再读一遍会话标题核对（私聊还要确认开着的不是群），核对通过才发；发的时候不再让微信按名字去模糊搜索，所以名字相近的群不会被发错。核对不上就当这一条没发出去（调用方收到「没发」的错），日志里写明要发给谁、实际开着的是谁。发自定义表情（点表情面板）、引用回复前找那条消息也都一样先切过去核对。
   **不抢焦点**：微信 4.x 上，wxauto4 切到别的会话、读消息的时候会把微信窗口顶到最前面、抢走键盘焦点（实测：读一次约 1～2 秒；只看会话列表不会）。程序的做法：每次这类操作做完，**立刻把前台还给原来的窗口、把微信放回原来的 Z 序**（你本来就在用微信的话不动，操作期间你自己点开了别的窗口也不去抢）；想连这 1～2 秒也看不见，就打开下面的「把微信窗口移到屏幕外」（读消息不用把窗口移回来，不会闪）。做不到的是：这 1～2 秒里键盘焦点仍然会在微信那边——实测过，边读边抢回焦点会把消息读坏，所以没这么做；这段时间别在别的窗口里打字，或者让机器人小号用另一台电脑。
9. **把微信窗口移到屏幕外**（同一处，默认关）：打开后，机器人运行期间微信主窗口放到所有显示器之外（不是最小化，最小化后读不到界面）；需要切换会话、发送、核对身份时短暂移回来，做完立刻移出去；停止机器人、退出程序时放回原位。**注意三点：运行中别用小号手动聊天；切换会话时窗口会闪一下；仍然不能最小化。** 身份核对没通过就不会移窗口，也不会启动。多显示器、高分屏都考虑了。万一窗口留在屏幕外（比如程序被强行结束），下次启动会自动放回来，也可以点账号页微信卡片上的「找回微信窗口」。**微信主窗口被藏到托盘（或最小化）时程序会自己把它显示回来，不用手动操作**：复核身份、读消息读不到界面时会先看一眼主窗口，被藏起来就显示出来（不抢前台焦点）再马上重试一次；连续几次还不行就把账号状态写成出错、写明原因并通知你，面板不会再一直显示「在线」却收不到消息。
10. **微信的「自定义表情」发出去之后**：点完那一格微信会自己把表情面板关掉，程序看到面板已经关了就不再按 Esc（以前多按的那一下会落到微信主窗口上，微信会把它藏进托盘）。只是翻着看、同步收藏时面板还开着，照旧按 Esc 关掉。

> 微信有没有更好的方案？更新的微信（4.1.12 以上）有靠读微信进程内存拿数据库密钥、往 Weixin.dll 内存里写字节的后台收发做法，杀毒软件容易报毒、封号风险更高，所以**没有采用**，保持界面自动化（wxauto4）。

### 非官方渠道（B站、贴吧、微博）——预览版，有风险，默认关闭

平台没有开放这些接口，是用网页登录态模拟的，**可能违反平台用户协议，账号有被限制或封禁的风险**。请用**小号**，先打开 **设置 → 回复 → 影子模式** 演练一阵（她只记下「本来会说什么」，不会真发）。

- 账号页里这几个平台默认不开；添加账号时要勾「我知道有风险」才能启动。
- 都是「评论区」形态：别人 **@ 她、回复她、给她发私信**，她才回；不主动插话。
- **评论、回复、私信分开设节奏和每日额度**（设置 → 平台）：每次动作前随机等一段时间（默认 15～45 秒）；本地去重（重启也不会重复回）；发送成功才记「已回复」，失败最多试 3 次。
- **遇到风控返回立即停止**（B站 HTTP 412/429、业务码 -412/-352/-509/-799；贴吧验证码/操作太频繁；微博「请求过于频繁」），并发 Windows 通知，不会原地重试。等 6～24 小时、在浏览器里正常登录一下再来。
- **B站**：点「扫码登录」用小号的 B站 App 扫码；支持评论 @ 回复和私信。直播弹幕**没做**：官方「直播开放平台」只能收自己直播间的弹幕且没有发弹幕接口，非官方直连风险更高。
- **贴吧**：填 BDUSS（浏览器 F12 → Cookies 里复制）；读「@我」并回帖。回帖风控很严（常用的开源库因为风险太高已经把回帖功能删了），请务必低频。
- **微博**：填 m.weibo.cn 的 Cookie；读「@我的评论」并回复，可选回私信。
- 这三个适配器的接口细节依据公开资料整理，**没有在真账号上验证过**（自动测试用的是模拟服务）。

## 十三、数据、安全与迁移

- **密钥加密**：服务商 API Key、各平台令牌、面板密码都存在本机数据库里，**用你的 Windows 账户加密**（DPAPI）。拷到别的电脑或别的 Windows 用户下就解不开——面板会提示「需要重新填」，不会出错。也可以让密钥完全不落盘：用环境变量（第四节）。
- **导出（换电脑、留底）**：设置 → 数据与迁移 → 导出数据包。默认**不带密钥**（更安全）；勾「带上密钥」会带上加密后的密文，**换电脑后读不出来，需要重新填一遍**。数据包里包括：全部设置、角色、人设（含历史版本）、人物表、记忆、聊天记录、自动备份、表情包图片，以及「撤销刚才的重置」用的那份备份（重置前的快照，含表情图片）。
- **导入**：新电脑上安装 → 打开 → 向导第一步设个密码 →「跳过向导」→ 设置 → 数据与迁移 → 导入，选那个 zip。QQ 要重新扫码；微信要登录小号并下载组件。
- **诊断包**：设置 → 系统 →「打包诊断信息」生成一个 zip（版本、去掉密钥的设置、近期日志；不含密钥、聊天记录和记忆；日志里的长数字只留末 4 位），报问题时附上。发出去之前可以自己解压看一遍。
- **新版本提醒**：设置 → 系统：每天查一次 GitHub Releases，有新版就在面板顶上提示；只提醒，不自动更新。
- **英文界面**：设置 → 系统 →「界面语言」选 English，刷新后整个面板变英文（默认中文）。聊天消息、人设正文这类内容不翻译；少数后台提示和日志还是中文。
- **装新版**：直接运行新版的安装包。安装程序只结束 PodMates 自己（主程序和面板窗口），**不停账号的 NapCat 和 QQ**（它们的文件在数据目录里，安装程序不往那里写）；装完重新打开程序，会接回原来的 NapCat，QQ 不用重新登录。程序拉起 NapCat 时不让它继承程序自己的运行库目录（`_internal`），NapCat 和 QQ 用自己目录和系统里的运行库，不会占着程序目录里的文件；万一有哪个 NapCat / QQ 进程还是从程序目录里加载了文件（比如旧版程序拉起、一直没重启的那个），装新版会覆盖不了，安装程序会把它连同同一个号的 NapCat / QQ 一起停掉（这个号需要重新登录一次，比装到一半失败好得多），并在数据目录留一条说明，下次启动时记进日志页（NapCat 类别，「安装程序：因占用程序目录文件而停掉……」）。
- **卸载**：开始菜单 →「卸载 群聊机器人面板」。卸载时会把 PodMates 启动的 NapCat 和 QQ 一起结束（它们占着文件，不结束删不干净）。会问要不要同时删除你的数据，默认「否」（保留，重装还能用）。开机自启的设置会一并清除。两种情况都不碰你自己开的 QQ。

## 十四、手机上用

- **同一个 Wi-Fi**：设置 → 访问与安全 → 打开「允许局域网访问」→ 右键托盘退出程序再打开 → 页面上会出现地址和二维码，手机扫码打开、输入面板密码。
- **添加到主屏幕**：iPhone 用 Safari 打开 → 分享 →「添加到主屏幕」；安卓 Chrome → 菜单 →「添加到主屏幕」。
- **在外面也想用**：用 Tailscale，步骤见下面一节。**不要**把面板直接暴露到公网。

### 在手机或别的电脑上用面板（推荐 Tailscale）

1. 在运行机器人的服务器（或电脑）、你的手机、你要用的其他电脑上，都装 Tailscale，并登录**同一个账号**。
2. 在面板「设置 → 访问与安全」里设好**面板密码**，打开「允许局域网访问」，然后右键托盘退出程序再打开。
3. 在服务器 / 电脑上的 Tailscale 里找到这台机器的 Tailscale 地址（形如 100.x.x.x），在手机或别的电脑的浏览器里打开 `http://<服务器的 Tailscale 地址>:<端口>`（端口默认 18765，设置里可改），输入面板密码。

开了「允许局域网访问」之后，面板**每个请求**都会检查来源地址，只接受这三类，别的一律拒绝（返回 403，并在日志里记一条）：本机（127.x、::1）；局域网私有地址（10.x、172.16～31.x、192.168.x、fc00::/7、fe80::/10）；Tailscale 这类组网工具用的地址（100.64.0.0/10）。所以面板放在云服务器上、监听了所有网卡，公网上的人也连不进来。
确实要让公网访问的话，才打开「也允许公网访问面板」（默认关）：这等于对整个互联网开放，走的是明文 http，密码和聊天内容都可能被人看到，也会有人来扫描、试密码，有风险，不建议。

## 十五、群里的分寸、学习与小工具

这一章的功能都是可选项，在 **设置 → 全局默认** 的「插话」「学习」「工具」分类里开关；全局、平台、角色、群各层都能单独设，没改的沿用上一层。

**默认开启的**

- **学群里的说话习惯**：每个群攒一份「风格画像」（句子长短、标点、常用的梗和口头禅、表情习惯；几个群绑到同一个记忆空间时共用一份，清空也一起清）。它在整理记忆的那次调用里顺带更新，**不额外花钱**；群友消息攒够 30 条才生成，样本不够不编造。她说话时只会稍微贴近一点，人设、身份与态度、回复语言、平台格式永远优先。在 **记忆 → 群风格画像**（或「群」页）能看、能改、能清空。角色层有单独开关；学术讲解、生活健康类模板默认关。
- **联网搜索**：主模型通过工具调用上网搜（需要当前模型支持工具调用；设置 → 模型与接口 里会显示支不支持）。搜索服务默认用 **DeepSeek 官方搜索接口**（`POST /v1/tools/search`，和 DeepSeek 聊天共用同一个密钥，按成功请求计费；官方说明从 2026-11-01 起独立调用开始计费），也可以换成 Kimi、智谱、Tavily、Brave 或自己搭的 SearXNG。搜索结果只用于当次回复，**不写进记忆**；用量单独记为「搜索」；每天最多搜多少次可设。
- **「记住……」和提醒**：对她说「记住我不吃香菜」，就写进你的人物备忘（来源标为「本人要求记住」，自动整理记忆时不会覆盖，不按天数清理；「忘掉我」可以删）。说「20 分钟后提醒我交作业」「明天早上 8 点提醒我开会」，到点由**当时在这个群值班的角色**用自己的口吻 @ 你提醒；每人同时最多 5 条（可设）；重启不丢；全部提醒在 **记忆 → 提醒** 里能看、能删。私聊也行，遵守私聊范围设置。
- **先用代码筛一遍，再问守门员**：没人@她的消息，纯表情、纯链接、签到、以 `/` 或 `#` 开头的指令、其他机器人发的消息，直接跳过，不调守门员（省一次调用）。只管主动插话，被@照旧必回。规则在 设置 → 全局默认 → 预筛规则 里改；人物表里可以把某人标成「机器人」。用量页显示「预筛省下的守门员调用」。
- **学表情包**：只学群里「常用」的——同一张图被多个人、或同一个人多次发过（默认 2 个人或 3 次）才学；近似图算同一张；用看图模型出描述并判断适不适合，不宜内容不学；每个群每天最多学 10 张、最多存 200 张，总容量 100 MB，满了先删用得最少的。发的时机和发哪张都由主模型在回复时决定（工具调用：按心情找出几张候选，她看描述自己挑，也可以都不选），频率可设；发一张算一条发言，计入插话上限；不能发图的平台自动跳过。在 **记忆 → 表情包** 里能看、能删。

**回复的长度、时效和用词**（设置 → 全局默认 → 回复，都是可调项）

- **群聊单次回复字数上限**（默认 300 字，私聊不限）：先在提示词里告诉她上限；写超了，就让模型自己压缩到上限以内（最多两次），还超才按整句收，**不会在句子中间截断**；拆条发送按压缩后的文字来拆。
- **过时回复**：生成回复期间群里又来了新消息（默认 3 条，或写了超过 20 秒后只要有一条），发送前用最新的上下文让模型重新判断——照发、改写，还是不发了（多一次调用，只在过时时才有）。同一个群里积压的多次 @ 会**合并成一次回复**，一起回、分别照顾到每个提问的人（评论区类平台各回各的，不合并）。
- **谁回复谁、@ 了谁**：给守门员和主模型看的聊天记录里，每一行都带上这条消息回复的是谁、@ 了谁，例如「张三（回复 李四）: ……」「（@海豚娘）……」；各平台拿得到这类信息的都照做。
- **主动插话前等对方说完**（「设置 → 插话」：「主动插话前等对方停几秒」默认 15，0 = 不等；高级项「最多等几秒」默认 30；全局 / 角色 / 平台 / 群各层都能设）：群里有人发了一条消息，不是马上去问守门员，而是等这个人停下来够这么多秒——这期间他又发了，就重新计时，从这一串的第一条算起到了「最多等几秒」就不再等，拿当时最新的那条去判断；守门员和她看到的是这一串完整的话。默认值的来历：同一个人接着发的下一条，69% 在 15 秒内到；一串连发，90% 在 29 秒内发完。**只管主动插话**：被 @、被回复、被叫名字、戳一戳照旧马上处理，私聊默认先等对方停 5 秒（见下面「私聊里等对方说完再回」）。等的这段时间也不卡群里其他消息；等的期间不问守门员、不额外调用模型，到点只问一次，冷却、名额、连发条数、闭嘴、禁言等条件那时再照常判断。等的期间别人发了消息，这一条就不再插，留给最新那条。
- **微信里的 @ 和引用**：微信的消息没有结构化的 @，程序把消息**开头**（前面只允许空白）的「@名字」认成 @ 了谁——名字要精确对上这个群里的成员（最近上下文里说过话的人的显示名，加上人物表里这些人的微信备注）；认出来的从正文里去掉，和 QQ 一样在聊天记录里显示成「（@某某）正文」，守门员和主模型因此分得清这句是对谁说的。对不上的、同名对着不止一个人的、写在句子中间的，保持原样文字；@ 她自己的照旧算叫到她。微信的引用消息，被引用的人名由 wxauto4 从消息里拆出来（`quote_nickname`），同样要精确对上群里的成员才记成「（回复 某某）」，引用的是她自己的话就和 QQ 一样算「回复了你」。
- **重复梗提示**：程序统计她在这个群最近 12 条发言（可调）里反复出现的梗、术语和比喻，下一次回复时提醒「最近已经用过……，这次换别的或不用」；纯统计，不额外调用模型。
- **两次回复最小间隔**（默认 10 秒，「设置 → 节奏」，全局 / 角色 / 平台 / 群各层都能设，0 = 不限）：她在一个群里发完一次回复后，同一个群里不到这么多秒不发下一次回复，每个群单独计时。被 @ 或被回复的消息不丢，排队等到点再回（这期间被叫到好几次的合成一条回复，处理前照常判断回复是否已过时）；主动插话直接不插，它和「插话冷却」各算各的，取更严的；同一次回复拆出来的几行照常连着发。私聊默认不受限，要限的话设「私聊里两次回复最小间隔」（按账号 × 对方各自计时）；体验模式和评论区类平台默认 0。
- **去掉括号里的动作描写**（默认开，「设置 → 回复」，全局 / 角色 / 平台 / 群各层都能设）：模型有时爱在回复里写「（尾巴晃了晃）」「（抱着书想了想）」这类动作描写。程序在**发送前**整理：整行只有一段这样的括号，删掉这一行；行首、行尾单独一段的，去掉这一段。夹在正文中间的括号、「（含税）」「（2019 年）」「（以上仅供参考）」这类补充说明一概不动；判断很保守（要有数字、英文、冒号的不算，要是明确的身体部位 + 动作或动作短语才算），宁可漏删，不会误删。人设里不用写任何限制句。
- **删掉回复里编出来的图片**（默认开，「设置 → 回复」，放在「去掉括号里的动作描写」旁边，全局 / 角色 / 平台 / 群各层都能设）：别人发的图在上下文里写成「[图片：描述]」，她自己发过的表情包写成「[表情包：描述]」，她有时会照这个格式在文字里编出「[图片：……]」冒充发了图，其实什么都没发。程序在**发送前**把**整行只是**一个（或几个连着的）媒体标记——「[图片：……]」「[表情包：……]」「[表情]」「[图片]」——的行删掉；夹在句子里的、标记后面还有别的字的一概不动，宁可漏删，不会误删。删完整条回复空了就不发文字；她调了表情包工具的话，表情照发。和「去掉括号里的动作描写」各管各的，一个关掉不影响另一个。
- **内部标注不会漏进正文**：回复开头如果出现「主动插话（……）：」「【被叫到】」这类程序内部的标注，发送前会自动去掉；主动插话的提示词也改成不再用容易被抄走的写法，并明确告诉她不要写标注。
- **换角色之后，旧角色的话不再被当成她自己说的**：同一个号换了角色（排班、「换××」指令）后，上下文里旧角色说过的话会标成「某某（这个号之前的角色）」，只有现在这个角色自己说的才标「你」（守门员那边是「她（自己）」）。
- **几个角色共用一个号，新角色不会把别人的自称当自己的**：群里看到的账号昵称（比如「某某🐬」）是轮流在岗的几个角色共用的。这个号在这个群（或这个私聊）里换过角色之后，系统提示词里会多一段【这个号上的几个角色】，只陈述事实：这个昵称是几个角色轮流用的，现在在岗的是谁，之前在这个号上说过话的还有谁，记录和记忆里写到这个昵称的地方指的是当时在岗的那个角色，她们各自的自称、口头禅、做过的事是她们自己的；有「群说话习惯」画像时，画像下面也加一句同样的说明。这个号上只出现过一个角色时什么都不加。人设里不用（也不该）写「你不是××」这类限制句。记忆整理时，机器人说的话会按「角色名（机器人角色）」交给模型（不再用账号昵称），要求前情里各个角色说的、做的事归在各自名下，群说话习惯画像也不再收机器人角色的口头禅；已经存下的记忆一条不改，旧的前情里写的账号昵称由上面那段说明兜住。
- **被群禁言了，这个号在这个群里就不再发言**：QQ 靠三种办法认出来——群禁言通知（针对这个号的禁言和解除，全员禁言的开和关）、发群消息时 QQ 返回的禁言类错误（NapCat 的 `result: 120`）、账号上线时主动查一遍各群（含全员禁言；全员禁言时这个号是群主或管理员不算）。知道结束时间的到点自动恢复，解除通知一到立刻恢复；只知道发送报了禁言错误、不知道什么时候结束的，隔一阵（先 5 分钟，之后翻倍，最长 30 分钟）用查询接口复查，**复查不往群里发任何东西**；查询一直失败满 48 小时、或这个平台根本查不了满 6 小时，就不再当它被禁言、自动恢复发言，并在日志里记一笔（之后照常发送，真被禁言会再认出来）。禁言期间这个号在这个群里不跑守门员、不写回复、不插话、不开冷场话题、不发定时消息 / 提醒 / 换班招呼 / 贴纸，也不为此调模型；照常收消息、存记录、整理记忆、学表情包，管理指令照样生效（只是不回话）。同群别的账号不受影响。状态存库，重启后还在，到期的启动时清掉。面板总览和「群」页写着「某号在某群被禁言，到几点」（不知道结束时间的写「结束时间未知」），总览「未读通知」每次禁言留一条，消息页「手动发言」时会提示「被禁言，没有发出」。Discord（超时）和 Telegram（限制发言）也接上了同样的机制；别的平台暂时没有。
- **资源监控**：程序每小时往 日志 页「资源」类别记一行：剩余物理内存、已用虚拟内存（commit）占上限的百分比、系统盘剩余空间、各账号在不在线、NapCat / QQ / 微信进程各几个。内存或硬盘快不够时用「出事时发消息给我」的同一套办法提醒你（面板总览也留一条未读通知，写明当前数值和占用最多的进程）：已用虚拟内存连续 5 分钟 ≥ 90%，或系统盘（PodMates 数据所在的盘）剩余 < 5GB。不看「剩余物理内存」，因为 Windows 会拿空闲内存做缓存，那个数平时就偏低。同一种提醒每天最多一次，恢复后再出问题算新的一次。这几个数和总开关在 设置 → 系统（高级）里，默认开；检查在程序现有的定时循环里做，内存每分钟查一次、硬盘每小时一次。
- **重启不丢状态**：群上下文（带着当时是哪个角色说的）、闭嘴和「别说了」的暂停、每小时 / 每天的插话计数、私聊的对话历史，重启或装新版后都会从数据库接上，不用等群里重新攒几十条。「重置记忆」清掉的上下文不会被找回来。
- **模型接口出错自动重试一次**：遇到 429、5xx、超时，自动重试一次；还不行就记日志，面板总览留一条通知。群里要不要发一句「断线了……」是个选项（设置 → 回复 → 高级「模型出错时在群里发一句」，默认关，打开后同一个群十分钟内最多发一次）。
- **「一条消息最多几个机器人回」只限制主动插话的**：被 @、被回复、被叫名字的机器人都会回，先占名额，剩下的名额才给主动插话的。
- **设置页有搜索框，分类能折叠**：表单最上面按名字或说明搜，高级里的也一起找出来；手机上分类默认折叠。
- **短句分条发**（默认开，QQ、微信、Discord、Telegram 等聊天类平台都生效）：回复里**每一行单独发成一条**，像真人一句一句打字；一行特别长（超过「一行超过多少字就按句子再拆」，默认 160 字）的再按句子拆。她一次连着发的条数受「中间没人说话时最多连着发几条」（默认 4）管：她在一个群里（或一个私聊里）发出的每一个气泡都算一条——拆出来的每一行、单发的表情包、紧接着的下一次回复；只要有别人说话（被@、被回复也是别人说话，我们的另一个账号开口也算；「有人戳她也算有人说话」默认开）就从 0 重新数。这次回复剩下的条数不够时，把合起来最短的相邻几行并在一起，并到剩下的条数为止；剩下 0 条时，主动插话、冷场开话题不发。私聊里按「哪个账号 × 哪个人」各数各的，对方说话就从 0 重新数；私聊里每次回复都是在回对方的话，按被@的规则，条数用完了也至少发一条；面板让她回、提醒、定时消息、指令回执不受这个上限拦，但发出的气泡照样计入；同一个群里我们的几个账号各数各的；0 = 不限。拆出来的几条发送中途群里来了新消息，剩下的照常发完。评论区类平台（X、Reddit、YouTube、B站、贴吧、微博）和 LINE（推送有额度）默认不拆，可以在平台设置里打开。
- **每小时最多回几次（每个群，含被@）**（设置 → 节奏，默认 0 = 不设）：每个机器人账号在每个群里有一份回复名额，最多攒到「名额最多攒几次」（默认 0 = 和每小时次数一样）那么多个；每回一次用掉一个，用掉的按「60 分钟 ÷ 每小时次数」的速度一个一个补回来，重启后还在。例：每小时 20 次、最多攒 5 次——一口气最多回 5 次，之后每 3 分钟补回一个，任意 60 分钟里不超过 25 次。**算一次**的：被@ / 被回复 / 被叫名字、戳一戳、主动插话、冷场开话题、单独发的表情包（一次回复不管拆成几条都算一次，后面跟的表情包不另算）；**不算**的：面板让她回、提醒、定时消息、指令和指令回执、用量用完时回的那句话。名额用完时：主动插话、冷场开话题直接不发（也不问守门员）；被@ / 被回复 / 被叫名字 / 戳一戳的不丢，排队到下一个名额补回来再回，期间被叫到好几次的合成一条回复；写好时已过时的走「发送前发现回复已过时」的重新判断；等的时候被闭嘴、被禁言、被关掉的作废。日志写「回复名额用完，约 X 分钟后回（已排队）」。「用户本人叫她不算进上限」（默认开；用户本人 = 人物表里固定的「用户」卡里的各平台账号）：他@她、回复她、叫她名字、戳她的那次回复不用名额，也不排队；他的发言引出的主动插话照常计入。和插话的各项上限、冷却、发言占比、「两次回复最小间隔」叠加，取最严。
- **主动插话时的引用**（设置 → 回复，默认开）：「主动插话时，被隔开了就引用她要回的那条」——发出去的时候，她要回的那条后面已经有「至少几条别人的消息」（默认 1）就引用那条；那条就是群里最新的就不引用。被@时的引用照旧由「回@时引用对方那条消息」管。QQ 和微信都支持：微信按 wxauto4 的消息 id 在聊天窗口里找那条消息再引用，找不到（比如已经滚出可见范围）就照普通方式发，日志记一笔。
- **她写的「@名字」发成真正的 @**（设置 → 回复，QQ、微信，默认开）：回复里的「@名字」，名字和这个群里能对上的成员（最近上下文里说过话的人的显示名，加上人物表里这些人的 QQ 昵称 / 微信备注）精确对上、后面是结尾 / 空白 / 标点时，QQ 把那段文字换成真正的 @ 段（可以在句中任何位置，不重复）；微信的 @ 只能在消息开头（wxauto4 的 `SendMsg(at=…)`），所以只转换写在**一行开头**（前面只有空白）的「@名字」，文字里原来那段去掉，句子中间的保持原样文字；同名对着不止一个人的、我们自己的账号、对不上的，保持原样文字。不在提示词或人设里加「你可以 @ 人」这类话。
- **QQ 小号收藏的表情也能被她用**（设置 → 工具，QQ 和微信，默认开；微信的见下面第二条）：程序用 NapCat 的 `fetch_custom_face` 取小号在 QQ 里收藏的表情（一次最多 500 张），新出现的图下载下来、用看图模型各写一句描述（按画面指纹认重复，每张只描述一次；一次最多新描述 40 张，剩下的下一轮接着做），从收藏里删掉的这里跟着删。启动、账号上线时同步一次，之后每隔「多久对一次收藏（小时）」（默认 24）同步一次；**记忆 → 表情包** 页里有「现在同步收藏」按钮，收藏的表情有「收藏」标记。收藏的表情属于这个账号，它所在的所有 QQ 群都能用（和本群学来的一起挑）；不占「每个群最多存几张」，容量满了先删用得最少的时也只删学来的；发一张和发别的表情包一样，计入发言、插话上限、每小时名额和连着发的条数。默认不按「是不是表情包、合不合适」丢弃（那是你自己挑的）；「收藏的表情也做内容检查」打开才检查。以 QQ 里的收藏为准：想去掉，在 QQ 里取消收藏。
- **被叫到时总给她表情包工具**（默认开，「设置 → 工具」，全局 / 角色 / 平台 / 群各层都能设，作用范围和「发表情包」一致）：被 @、被回复、被叫名字的那次回复，只要这个平台能发、这个账号有可用的表情，就一定给她 `send_sticker` 工具，不再看「多大概率给她这个工具」。**给工具不等于每次都发**：发不发由她看气氛决定。主动插话、冷场开话题按「多大概率给她这个工具」给，**默认 100%（每次回复都给）**，嫌她发得多就调低；关掉这个开关，被叫到也按概率给。**私聊里也能发表情包**：只从这个账号自己的收藏里挑（QQ 收藏表情、微信自定义表情），私聊没有学来的表情包；私聊每次回复都是在回对方，按「被叫到」处理，所以这个开关在私聊里同样生效；QQ 用 NapCat 往私聊发图，微信在那个私聊里打开表情面板、按指纹点；发一张算私聊里连着发的一条。这一次回复没给她工具（概率调低了、平台不能发、模型不支持工具）、而「发表情包」开着且本该有表情可用时，系统提示词末尾会加一句「这次回复发不了表情包，只能发文字。」，免得她说要发却什么也没发；「发表情包」关了或账号根本没有表情包时不加。

**别的机器人**：群里有别的 AI 时，在人物表里把它的卡勾上「这是别的机器人」（默认关，只表示「这个账号是 AI」）。怎么对待它，和别的插话设置一样按分层继承（全局、角色、平台、群）；单个角色可以设成不跳过守门员，只影响这个角色。选项：「别的机器人的消息跳过守门员」（默认开）；「别的机器人 @ 她或回复她时」三档——不理它 / **最多接 N 轮**（默认 1 轮，和同一个别的机器人连续互接到 N 轮就停，等真人在这个群开口后重新计数）/ 照常回复。这个计数和我们自己几个机器人之间的互接上限分开算。

**按需打开的（发言占比上限默认是开的）**

- **发言占比上限**（默认开）：在「统计最近几条」（默认最近 15 条消息，只数条数、不花 token）里，我们所有机器人在这个群的发言合计到了上限，就暂停主动插话；被@照回。上限有两种设法，在「统计方式」里选：**按条数**（默认）设「最多几条」（默认 7，即最近 15 条里她们已经说了 7 条就不再插）；**按比例**设「最多占比（%）」（默认 47，和 15 条里 7 条差不多，四舍五入到整数百分比再比）。她一次回复拆成几行，按行算条数。「样本少时不拦」（默认关，条数可调、默认 10）：最近的消息还不满这个条数时不拦，主要配合按比例使用（消息很少时一两条发言就是很高的比例），按比例时建议打开。从旧版升级时，设过占比百分比或统计窗口的，会自动改成「按比例」并打开「样本少时不拦」，原来的百分比不变，效果和以前一样。
- **插话力度自动调节**：守门员顺带判断她上一次主动插话有没有人接——顺着聊下去就回升，被无视或被嫌烦就调低；在你设定的力度上下几档（默认最多低 2 档、高 1 档）之内，每个机器人在每个群分开算，**会随时间回升**，不会一路降到零。「群」页能看当前力度和最近的调整原因。和账号级上限、冷却、占比上限叠加，取最严的。
- **有人说「别说了」就暂停主动插话**：由守门员判断（同一次调用，不额外花钱，不靠关键词）。该群所有机器人暂停主动插话（默认 30 分钟，一小时内反复被叫停就翻倍，最长 480 分钟）；被@照样回，有人@她就提前恢复。管理员的「闭嘴」指令仍然更强：完全静音。
- **用量硬上限**：设了「每日用量上限」后，打开它，当天用量到了上限，被@和私聊也不再调用模型，只回一句固定的话（默认「今天的额度用完了，明天再来」，每个角色可以设成自己口吻的一句）；记忆整理、看图、搜索、学表情包、接口向量也一律暂停（本机向量不受影响）；第二天自动恢复，总览和用量页会显示当前状态。首次设置向导里会提醒你设一个每日上限（默认 0 = 不限）。

## 十六、重置记忆

面板 → **记忆 → 记忆条目** 里有「**重置记忆…**」：想让她「忘光重来」，或只忘某个群、某个人时用。

- **范围**（单选）：全部 / 某个记忆空间 / 某个群 / 某个人。
- **内容**（多选，默认全选）：人物备忘、群前情、群梗（连同向量）、文件片段、群风格画像、表情包、提醒、最近的聊天上下文（模型看到的最近若干条；覆盖所有会话，包括还没加载进内存的，重置后她不再记得「刚才在聊什么」）。
- 确认框会列出每一类将删掉多少条，确认后才执行。
- **重置前自动备份**所选范围的内容（`backups` 文件夹里，另外照每日备份体系做一份整库备份）；记忆页顶上会出现「**撤销刚才的重置**」，在下一次重置之前一直有效，撤销会完整恢复（含向量、表情包图片、提醒、聊天上下文）。
- **人物表、人设、设置、用量不在重置范围内**，一行都不会动。

另外，记忆条目列表上有「**全选当前筛选结果**」，配合「删除所选」「通过所选」批量处理（列表最多显示 300 条）。

## 十七、自定义指令

面板 → **指令**：自己定义「群里有人这样说，就做这件事」。默认一条都没有。

每条指令由这几部分组成：

- **触发**：要不要先 @ 她（开 = 要 @ 她、回复她或叫她的名字；关 = 群里任何人说都触发，只由一个机器人回）；匹配方式三选一：**完全相等** / 包含 / 正则。
- **动作**，四种：① **固定回复**——原样发文字，不调模型，可以写 `{name}` 代表说话人；② **让角色回答**——带上你写的提示，她用自己的口吻回答，走正常的人设拼装，调一次模型；③ **执行内置指令**——相当于给内置指令起别名，比如「@她 睡觉」= 闭嘴 480 分钟；④ **随机发一句**——从你写的几句里随机发一句，不调模型。
- **谁能用**：所有人 / 只有我（人物表里的管理员）/ 指定的人 / 某个分组 / 群主和群管理员。没权限的人说了，当没触发，照常聊天。
- **在哪里生效**：平台、在岗角色、群，都可以限定（不选 = 全部）。
- **冷却时间**：每条单独设，同一个群里两次触发之间至少隔这么久；冷却中静静地不理。

面板里可以添加、编辑、删除、拖动排序（越靠前越先匹配）、启用停用，整张表可以**导出 / 导入 JSON**；编辑框里有「试一试」，输入一句话看会触发哪条（不会真的执行）。

**给内置指令起别名时的权限**：动作选「执行内置指令」，「谁能用」默认是「跟随这条内置指令的权限」（和直接对她说这条指令一样，默认只有管理员）；想让所有人都能用要自己改成「所有人」，编辑框和列表里都会提醒「对所有人开放」。

**匹配顺序：自定义指令 → 内置管理指令（闭嘴、换人设……）→ 正常聊天。** 自定义指令能盖住同名的内置指令。**不提供脚本或代码执行。** 自定义指令受影子模式（只记不发）和静默时段约束；用量硬上限生效时，只有「让角色回答」不执行，其余三种照常。

## 十八、常见问题

| 问题 | 怎么办 |
|---|---|
| 打开安装包提示「Windows 已保护你的电脑」 | 点「更多信息」→「仍要运行」 |
| 桌面图标双击没反应 | 程序可能已经在托盘里了，看右下角；双击会把已开的面板调到前面 |
| 她不说话 | 总览看有没有红色提示；确认服务商密钥填了、账号「在线」、机器人「运行中」；看日志页有没有「生成失败」 |
| 日志里报余额不足 / 限流 | 设置 → 模型与接口 → 打开「主服务商出错时切到备用」并选一个备用 |
| 服务商卡片显示「换了电脑，密钥读不出来」 | 密钥是按原来那个 Windows 用户加密的，在这台电脑上重新填一遍；或改用环境变量 |
| QQ 一直「连接中」 | NapCat 没起来或没登录：账号页看提示；日志页看原因 |
| QQ 被踢下线 / 风控 | 面板「总览」页留一条「未读通知」；同时发消息给「用户」卡上的账号（挑一个别的在线账号发，出事的那个除外），Windows 上还会弹通知。歇一阵再登录，或降低插话频率 |
| 重启 / 装新版后，QQ 小号又要扫码 | 看日志页（NapCat 类别）：程序会把 NapCat 的登录过程翻成几句话——「正在用登录记录快速登录」、「未找到该 QQ 历史登录记录」（多半是这次启动用的 Windows 用户或 QQ 数据目录和上次不一样，对照「启动时的 Windows 用户」和「QQ 数据目录」两行）、「这个号已经在另一个 QQ 进程里登录着」（上一次遗留的 QQ 没退出，现在启动前会自动清掉）。装新版时安装程序只结束 PodMates 自己，NapCat 和 QQ 继续挂着、装完接回去（日志里有「接回了已在运行的 NapCat，QQ 没有重新登录」；没接回的话，同一类别里有「没能接回原来的 NapCat（原因）」）；卸载时才会连 PodMates 启动的 NapCat 和 QQ 一起结束。都不碰你自己开的 QQ |
| 她插话太多/太少 | 角色或群里调「插话力度」；或在群里 @她 说「插话力度 2」；每小时上限在 设置 → 全局默认 → 插话 |
| 想看她本来会说什么但先不发 | 角色或群设置里打开「影子模式」，到「消息」页看虚线框 |
| 记错了人 | 记忆页找到那条，编辑或删除；也可以在群里 @她「忘掉 某人」 |
| 微信不工作 | 微信窗口别关别最小化；版本检查是否黄色；聊天名字要和微信里显示的一模一样 |
| 微信主窗口被藏到托盘 / 不见了（收不到消息、面板还显示在线） | 程序会自己把它显示回来，不用手动操作：复核身份或读消息读不到界面时先看主窗口，被藏起来就显示出来再重试一次。连续几次还不行，账号状态会变成出错并写明原因（以前会一直显示「在线」）。也可以点账号页微信卡片上的「找回微信窗口」 |
| Discord / Telegram 连不上 | 国内要填代理，账号上勾「使用代理」；令牌错了就重新生成 |
| 非官方渠道（B站等）突然停了 | 多半是遇到了平台风控（看账号状态里的原因和 Windows 通知）。先别急着重启，等 6～24 小时、在浏览器里正常登录一下，降低额度再来 |
| 忘了面板密码 | 在电脑上从桌面图标打开面板（本机窗口免密码）→ 设置 → 访问与安全 → 改密码 |
| 想让某个号在某个群换个角色 | 「排班」页加一条规则；只是临时换就在群里 @她「换温和版群友 2小时」 |
| 连模型接口报 unable to get local issuer certificate（证书校验失败） | 多见于刚装好的 Windows：系统的根证书是「用到才下载」的，旧版会碰到。现在程序自带一份根证书（Mozilla 那份），同时仍信任 Windows 证书库里的企业 / 代理证书；证书校验始终开着，没有也不会提供「忽略证书错误」的选项。升级到这一版就好 |
| 连微信报 Find Control Timeout（找不到「微信」标签） | 有的微信界面把品牌名显示成「WeChat」（英文品牌），wxauto4 里写死的是「微信」，旧版会连不上。现在程序在加载 wxauto4 时补了兼容：导航栏的标签、主窗口叫「微信」「WeChat」「Weixin」都认（不改 wxauto4 的文件）。还连不上的话，状态栏里的报错会列出微信界面上实际找到的导航标签名，方便排查 |
| 她想不起意思相关的旧事 | 看「记忆 → 语义回忆」开关和「已建向量」数；换过模型程序会自动重建，页面上写着进度或暂时算不了的原因 |
| 想让她看懂群里的图片 | 设置 → 模型与接口 → 打开「看图」并选能看图的模型（可按平台、按群单独开）；每张图多一次模型调用 |
| 想把一切恢复到某天 | 数据目录的 `backups` 里有每天的自动备份（整份数据库） |
